Keep your own data

Signs a customer in to Supabase with their SolarAssistant account, without sending them to solar-assistant.io. Runs from source with no build step.

Setup

Kept in this browser only. The application needs no redirect URI for this flow.

1. Sign in to the portal 

  






  2. Exchange the session for an identity token, and sign in to Supabase
  
Two requests: one to us for the token, one to Supabase to spend it.

  
  






  3. Prove row-level security
  
Needs a table. Run this in the Supabase SQL editor first:

  
create table service_notes (
  id      bigint generated always as identity primary key,
  user_id uuid not null default auth.uid(),
  site_id bigint,
  note    text not null
);

alter table service_notes enable row level security;

create policy "own rows" on service_notes
  for all using (user_id = auth.uid()) with check (user_id = auth.uid());
